# SplitMate 💸
> Split expenses, not friendships

A full stack group expense sharing web application built with Java Spring Boot and React.

## 🌐 Live Demo
- Frontend: https://splitmate.vercel.app
- Backend: https://splitmate-backend.railway.app

## ✨ Features
- 🔐 JWT Authentication with BCrypt
- 👥 Create and manage groups
- 💳 Add expenses with Equal, Exact and Percentage split
- 🧠 Greedy debt minimization algorithm
- ⚖️ Real time balance tracking
- ✅ Settle up feature
- 📧 Automatic email notifications via Gmail SMTP
- 🔒 OTP based password reset
- 🌙 Dark mode
- 📱 Mobile responsive
- 🔍 Search and filter expenses

## 🛠️ Tech Stack

### Frontend
- React 18 + Vite
- React Router v6
- Axios
- Lucide React Icons

### Backend
- Java 17
- Spring Boot 3.5
- Spring Security
- Spring Data JPA
- Hibernate
- JWT Authentication
- Gmail SMTP

### Database
- MySQL 8
